# 🧪 Guilda dos Alquimistas

> Uma aplicação web interativa desenvolvida com foco em operações CRUD (Criar, Ler, Atualizar e Deletar), integração com APIs externas e manipulação avançada de dados.

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido para consolidar conhecimentos fundamentais de desenvolvimento front-end, incluindo consumo de APIs REST, manipulação dinâmica do DOM, gerenciamento de formulários e estruturação de interfaces limpas e responsivas. A aplicação utiliza uma temática imersiva de alquimia para organizar e gerenciar dados de forma interativa.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica e organização das páginas.
* **CSS3:** Estilização visual, design responsivo e identidade temática.
* **JavaScript (ES6+):** Lógica da aplicação, requisições assíncronas (`Fetch API`), manipulação do DOM e tratamento de eventos.
* **Git & GitHub:** Controle de versão e hospedagem do código.

---

## ⚙️ Funcionalidades
* **Operações CRUD:** Permite adicionar, visualizar, atualizar e remover registros de forma dinâmica.
* **Consumo de API:** Integração com dados externos para alimentar o sistema.
* **Interface Responsiva:** Layout adaptado para diferentes tamanhos de tela.
* **Feedback Visual:** Alertas e atualizações na tela em tempo real conforme as ações do usuário.
